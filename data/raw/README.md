# Raw data

Download the PaySim dataset from Kaggle:

https://www.kaggle.com/datasets/ealaxi/paysim1

1. Click **Download** (a free Kaggle account is required) and you'll get `archive.zip` (~180 MB).
2. Extract it and place the CSV in this folder:

```
data/raw/PS_20174392719_1491204439457_log.csv
```

(~470 MB, 6,362,620 rows, 11 columns). Do not rename it; or, if you do, update `RAW_CSV` in `src/data_prep.py`.
